💍 Wedding Admin

Private dashboard — RSVPs, headcount & wishes. Not linked from the invitation.

Firebase isn't configured yet. This dashboard needs the same Firebase project the invitation uses.
  1. Copy config.example.js → config.local.js and paste your Firebase web config (Console → Project settings → Your apps).
  2. In the Firebase console: Authentication → Sign-in method → enable Email/Password.
  3. Under Authentication → Users → Add user, create ONE account for the couple (that's the login for this page).
  4. Publish the Firestore rules from the top of firebase.js — they let a signed-in user read RSVPs and read/delete wishes, while guests can still only submit.
  5. Reload this page and sign in.
